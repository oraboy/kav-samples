## Add your story

Made something with Kav and happy to show it? Either:

- send the PDF (or a link to your reader) to whoever invited you to try Kav, and say how you would like to be credited, or
- open a pull request that adds one folder: `<your-story>/` with the PDF and, if you have it, an `index.html` reader. Copy `the-ant-who-walked-alone/` as a starting point.

Say in the pull request that the story is yours and that you are happy for it to be public.
